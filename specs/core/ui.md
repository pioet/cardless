模式 A：还没有选中牌

这时操作对象是 当前 pile。

底部显示：

Deck
[手选] [顶部 ×1] [随机 ×1] [全部] [洗牌]

或者更清楚一点：

从 Deck 选择牌
[手选] [顶部 ×1] [随机 ×1] [全部]
[洗牌]

这里 洗牌 是 pile-level action，和 pick action 同级，但它不会进入 move。

模式 B：已经选中牌

这时操作对象变成 已选中的 cards。

底部立刻切换成：

已选 3 张
[移动到...] [翻面] [取消]

不再显示 [手选] [顶部] [随机] [全部] [洗牌]。

这样用户心智很清楚：

没有选牌 → 选择牌 / 操作牌堆
已经选牌 → 移动这些牌
